# Weather System

**GG Studio**

## Requirements

- [gg_lib](https://github.com/GGStudioCFX/gg_lib/releases/latest) 1.0.20 or newer

## Install

1. Put `gg_weathersystem` in your `resources` folder.
2. Remove any other weather script (`qb-weathersync`, `qbx_weathersync`, `cd_easytime`, `Renewed-Weathersync` or `vSync`).
3. Add these lines to `server.cfg`, in this order:

```
ensure gg_lib
ensure gg_weathersystem
```

4. Restart your server.

## Setup

Every setting is in game. Type `/ggsettings` and pick **Weather System**.

Type `/weather` to open the weather panel.
