**DrugFarm** is a production facility for illegal-trade roleplay, complete with a processing area and holding cells for the scenes that follow a raid.

## What's inside

| Area | Use |
|---|---|
| **Drug processing area** | Production roleplay |
| **Two holding cells** | Detention and interrogation scenes |
| **Custom props** | Purpose-built for the location |

## Location

- `-34.5375, 2879.5640, 62.09241`

## Requirements

- FiveM server (OneSync recommended)
- No framework required — works on ESX, QBCore, QBox, OX and standalone

## Installation

1. Download the resource and place it in your `resources` folder
2. Add it to your `server.cfg`:
   ```cfg
   ensure iak_drug_farm
   ```
3. Restart the server
