**Pipeline Inn** is a surf-themed roadside restaurant nestled by the beach — a complete MLO built for business roleplay, faction hangouts, staff activities and everyday server life. Coastal ambiance outside, a fully usable interior inside.

## What's inside

| Area | Use |
|---|---|
| **Entrance** | Reception and waiting area |
| **Dinner Hall** | Main dining floor for service roleplay |
| **Office** | Manager and paperwork scenes |
| **Kitchen** | Food preparation |
| **Warehouse** | Stock and deliveries |
| **Bathroom** | Fully modelled interior |

## Requirements

- FiveM server (OneSync recommended)
- No framework required — works on ESX, QBCore, QBox, OX and standalone

## Installation

1. Download the resource and place it in your `resources` folder
2. Add it to your `server.cfg`:
   ```cfg
   ensure iak_pipeline_inn
   ```
3. Restart the server
