**YachtClub** brings an upscale waterfront venue to your server — a yacht club interior suited to luxury roleplay, private events, business meetings and high-end faction scenes.

## Location

- `-786.5088, -1349.0610, 10.8560`

## Requirements

- FiveM server (OneSync recommended)
- No framework required — works on ESX, QBCore, QBox, OX and standalone

## Installation

1. Download the resource and place it in your `resources` folder
2. Add it to your `server.cfg`:
   ```cfg
   ensure iak_yatchclub
   ```
3. Restart the server
