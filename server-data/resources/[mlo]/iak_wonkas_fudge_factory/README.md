**Wonka's Fudge Factory** is a three-floor industrial interior with everything a production-themed storyline needs, from the public hall down to the back offices.

## What's inside

| Area | Use |
|---|---|
| **Hall + waiting room** | Public-facing entrance |
| **Changing room** | Staff areas |
| **Boss room** | Management scenes |
| **Recording room** | Media and events |
| **Three floors** | Full vertical layout |
| **Custom props** | Purpose-built for the location |

## Location

- `481.14, -99.99, 63.06`

## Requirements

- FiveM server (OneSync recommended)
- No framework required — works on ESX, QBCore, QBox, OX and standalone

## Installation

1. Download the resource and place it in your `resources` folder
2. Add it to your `server.cfg`:
   ```cfg
   ensure iak_wonkas_fudge_factory
   ```
3. Restart the server
